# 장 마감 종가 워밍업 Decisions

이 문서는 연결 Monolith 작업에서 사용자에게 하나씩 확인해 확정한 Batch 관련 결정을 기록한다.

## D4. 종가 사전 적재 범위와 시각

- 상태: 확정
- 결정: **A — 전체 등록 종목을 평일 15:40 KST에 적재하고 불완전할 때만 복구 실행한다.**
- 확정일: 2026-08-21

적용:

- 전체 등록 종목 중 6자리 국내 주식 심볼을 대상으로 한다.
- 기존 KIS 30종목 분할 호출을 재사용한다.
- 누락 종목만 최대 3회 재시도한다.
- 재시도 후 누락이 남으면 Batch Job을 실패 처리한다.
- 지연 기동·수동 복구용 application entry point를 제공한다.

## D5. 종가 보존 기간

- 상태: 확정
- 결정: **A — 달력 기준 최근 30일을 보존하고 이전 데이터만 삭제한다.**
- 확정일: 2026-08-21

적용:

- 장 시작 시 전체 삭제 작업을 제거한다.
- 매일 16:30 KST에 30일 이전 데이터만 정리한다.
- 최근 거래일 종가는 장 시작과 재시작 이후에도 유지한다.

## D6. Monolith와 Batch 전달 방식

- 상태: 확정
- 결정: **A — 저장소별 연결 Issue, Issue 번호 브랜치와 PR로 함께 전달한다.**
- 확정일: 2026-08-21

적용:

- Batch Issue #1과 Monolith Issue #7을 상호 연결한다.
- Batch PR과 Monolith PR에 권장 배포 순서와 상대 PR을 기록한다.
- Batch를 먼저 배포해 종가를 준비한 뒤 Monolith를 배포한다.
- 승인과 병합은 사용자가 수행한다.
